# Task Card Mailbox

One card per coordinated task: `tasks/<TASK-ID>.md`, created from
[`../templates/task_card.md`](../templates/task_card.md). The protocol is
[`../../../skill/parallel_workboard.md`](../../../skill/parallel_workboard.md).

A worker edits only the card it has claimed. Preparing a card, or setting it
`PREPARED`, never authorizes execution.
