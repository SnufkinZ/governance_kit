# Architecture Decision Records (placeholder)

> Rename to `docs/decisions/CLAUDE.md` (or keep a README) in the target repo.
> Use `ADR-template.md` (in this folder) for each new record.

This directory records significant decisions that should survive beyond the
changelog.

- Changelog entries answer: **what changed?**
- ADR entries answer: **what was considered, what was accepted or rejected, and why?**

Use an ADR when reversing the decision later would require re-reading more than
one design document, or when a rejected proposal is likely to look attractive
again to a future AI session. Numbered sequentially: `ADR-0001-<slug>.md`.

Empty for now — but present from day one so the AI never makes an architectural
choice the loop meant to capture simply because "there was no ADR folder yet"
(BOOTSTRAP.md axiom A2).
